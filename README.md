# Treinamento Industrial — Trópicos

Aplicação inicial para organizar treinamentos industriais por equipamento.

## Módulos planejados
- Rebobinadeira REW-450 AFH
- Cortadeira LS-30.1 AFH

## Desenvolvimento
```bash
npm install
npm run dev
npm run build
```

A versão inicial é uma interface de navegação e não substitui os manuais oficiais nem a capacitação supervisionada. Os procedimentos específicos serão elaborados e conferidos com os manuais de cada máquina antes de serem publicados. Nenhum banco de dados é necessário nesta primeira etapa.
